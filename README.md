# astroduel2-overlay

In-game overlay mod for [**Astro Duel 2**](https://store.steampowered.com/app/655350/Astro_Duel_2/) on Steam, Windows x64.

### Features:
- Custom level loading (Versus only)
- Level pool management (Versus only)
  - Custom level selection per-world
  - New random level selection modes 

## Installation
### Installer
1. Download and unzip latest release.
2. Double click the Install.ps1 powershell script.
3. Copy the path to your Astro Duel 2 install directory into the terminal.
4. Press enter.
   
Note: The installer script will fail if Astro Duel 2 is not found, or is an unsupported version.

### Manual
1. Download and unzip latest release.
2. Navigate to your Astro Duel 2 install directory.
3. Rename the existing `steam_api64.dll` file in the Astro Duel directory to `steam_api64_real.dll`.
4. Copy the mod's `steam_api64.dll` file into the Astro Duel directory.

## Build
### Requirements
- Visual Studio 2022
- CMake ≥ 3.25
- vcpkg
  - Minhook
  - imgui
  - SDL3
  - enchantum

### CMake
- `steam_api64`: builds the overlay mod / proxy dll.
- `deploy`: builds `steam_api64`, and then deploys the built files to the game's install directory
using [tools/CopyAndRun.ps1](tools/CopyAndRun.ps1).
  - The `deploy` target requires the CMake cache variable `GAME_DIR` to be defined. See
[cmake -D](https://cmake.org/cmake/help/latest/manual/cmake.1.html#cmdoption-cmake-D).

Debug builds are not supported because of ABI incompatibility between Debug and Release modes in MSVC.
Instead, the `RelWithDebInfo` configuration uses the MSVC flag `-UNDEBUG` to enable the C 
[`assert`](https://en.cppreference.com/c/error/assert) macro. 

For more info on the vcpkg integration, see [CMakePresets.json](CMakePresets.json) and 
[vcpkg in CMake projects](https://learn.microsoft.com/en-us/vcpkg/users/buildsystems/cmake-integration).

Minhook uses a custom overlay port implemented to build a static library. For more info, see [overlay-ports/minhook](overlay-ports/minhook)
and [Overlay ports](https://learn.microsoft.com/en-us/vcpkg/concepts/overlay-ports).

## Implementation
This mod ships as a `steam_api64.dll` proxy, replacing the game's Steam DLL, and re-routing
function calls to the original Steam DLL renamed to `steam_api64_real.dll`. A worker thread
spawned from [`DllMain`](src/dllmain.cpp) waits for the game to unpack, then hooks the import address table and 
various game functions.

For more info on spawning a worker thread from [`DllMain`](src/dllmain.cpp), see 
[The Old New Thing - Does creating a thread...](https://devblogs.microsoft.com/oldnewthing/20070904-00/?p=25283/).

For more info on the ABI compatibility that this project relies on, see 
[C++ binary compatibility...](https://learn.microsoft.com/en-us/cpp/porting/binary-compat-2015-2017?view=msvc-170).

### Proxy DLL
The mod's DLL proxy implementation may be found in [src/steam_forwards.inc](src/steam_forwards.inc), which
is generated by [tools/generate_steam_proxy.py](tools/generate_steam_proxy.py). This generated file uses the MSVC
linker option [/EXPORT](https://learn.microsoft.com/en-us/cpp/build/reference/export-exports-a-function?view=msvc-170) 
to reroute all `steam_api64.dll` functions to `steam_api64_real.dll`. None of these functions are reimplemented, or
hooked onto by the mod's DLL.
