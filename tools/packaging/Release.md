## v1.0.0-beta
### Installation
#### Installer
1. Download and unzip.
2. Run the `Install.ps1` PowerShell script.
   1. In Windows 11, right click and select "Run with PowerShell".
3. Copy the path to your Astro Duel 2 install directory into the terminal.
4. Press enter.

Note: The installer script will fail if Astro Duel 2 is not found, or is an unsupported version.

#### Manual
1. Download and unzip.
2. Navigate to your Astro Duel 2 install directory.
3. Rename the existing `steam_api64.dll` file in the Astro Duel 2 directory to `steam_api64_real.dll`.
4. Copy the mod's `steam_api64.dll` file into the Astro Duel 2 directory.
